# Hospital Management System - Logic & Database Testing

## 📌 Project Overview
This project showcases the extensive Manual Testing, Input Validation, and SQL Database Verification performed on a Python and SQLite-based Hospital Management desktop application. The scope includes verification of core business rules such as patient onboarding constraints, slot scheduling, and database referential integrity.

## 🛠️ Tools & Technologies Used
* **Documentation:** Microsoft Excel
* **Backend Framework:** Python (OOPs & Functions)
* **Database Environment:** SQLite / MySQL Basics
* **Testing Concepts:** Functional Testing, Negative Testing, Database (SQL) Testing, Integrity Constraints Verification

## 🗂️ Modules & Constraints Tested
1. **Patient Onboarding:** Validated complete profile builds and executed negative constraints checking on 10-digit mobile number fields.
2. **Appointment Scheduling:** Tested operational availability logic for doctor booking slots and confirmation outputs.
3. **Billing Calculations:** Evaluated field formatting constraints against abnormal negative numerical entries.
4. **Database Verification (SQL Testing):** Ran explicit `SELECT` validation statements to match front-end data inputs with SQLite backend table column records. Verified cascade effects on structural tables during record updates.

## 📄 Deliverables Attached
* **Hospital_Management_Testing_Project.xlsx:** Detailed manual functional and database test cases containing operational unique IDs, structural steps, and clear validation criteria.
